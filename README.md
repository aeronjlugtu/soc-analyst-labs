
<h1> SOC Analyst Labs</h1>

<h2>Description</h2>
</b>This repository contains Security Operations Center (SOC) investigation labs and alert triage write-ups completed as part of the SOC Level 1 learning path on TryHackMe, along with additional investigations from LetsDefend.
<br />

</b>The purpose of this repository is to document practical blue team investigations and demonstrate core SOC analyst skills such as alert triage, log analysis, threat detection, and incident response. Each investigation follows a structured SOC workflow including reviewing alerts, analyzing logs and artifacts, identifying malicious activity, and determining appropriate remediation steps.
<br />


<h2>Skills Demonstrated</h2>

- <b>SOC Alert Triage</b> 
- <b>Basic SIEM Investigation</b>
- <b>Phishing Investigation</b>
- <b>Threat Detection</b>
- <b>Log Analysis</b>
- <b>MITRE ATT&CK Mapping</b>
- <b>Malware Analysis</b>

<h2>Platforms Used</h2>

- <b>TryHackMe (SOC Level 1 Path) </b>
- <b>LetsDefend </b> 

<h2>Structure</h2>
</b> Each investigation is documented as a structured report including the alert summary, investigation process, evidence collected, analysis findings, and final conclusion. <br />
